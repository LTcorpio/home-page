# home-page

局域网自用的导航首页：把常用服务收拢到一页，提供分组卡片、可达性状态与容器启停。

## 核心功能

| 模块 | 说明 |
| --- | --- |
| 导航卡片 | 按分组展示服务，图标 + 名称 + 描述，点击在新窗口打开 |
| 图标来源 | 自动抓取站点图标、上传图片、文字图标三种方式 |
| 可达性状态 | 由浏览器直连目标地址判断在线 / 离线，状态点实时反馈；支持手动刷新与定时复探 |
| 探测控制 | 站点总开关、分组豁免、设备开关三级控制，可按需关闭以避免误判 |
| 容器管理 | 卡片可绑定一个或多个容器，右键（移动端长按）批量启停、重启 |
| 身份与权限 | 对接 SSO，按用户组区分管理员与访客；卡片可按组授权，未授权不可见 |
| 管理后台 | 分组、卡片、站点设置的增删改与排序；可控制卡片描述对不同身份的显隐 |
| 卡片备注 | 管理员可为卡片记录备注或凭证，仅管理员可见 |
| 禁用策略 | 卡片可单独禁用，禁用卡片对管理员 / 访客的显示策略分别配置 |
| 页面偏好 | 探测开关、复探间隔、打开即探测、时钟显示秒等设置按设备保存 |
| 页面时钟 | 显示日期、星期与时间，按服务端时间校准，避免本机时间偏差 |

## 技术栈

- 后端：Go + SQLite，单二进制运行，同时托管前端静态资源
- 前端：React + TypeScript + Vite + Tailwind CSS
- 容器：直连 Docker Engine API，查询状态并执行启停

## 开发与构建

```bash
make dev     # 启动前端开发服务与后端
make build   # 构建运行镜像
make deploy  # 构建并重启容器
```
